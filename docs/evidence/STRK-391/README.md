# STRK-391 — Slot Mintage evidence

Version 3.36.38 adds optional Mintage to each Custom Collection Slot. Unknown
omits the field; zero is retained. Create/Edit and Clone & customize carry the
count, while Album and Ledger use their existing formatting.

## Screenshots

- `mintage-1280-{light,dark,slate,sepia}.png`: the single desktop row, with Mintage
  beside Year and existing insert/reorder controls.
- `mintage-375-{light,dark,slate,sepia}.png`: the mobile row, with Mintage wrapping
  below the label and Year.
- `mintage-album.png` and `mintage-ledger.png`: formatted 25,000 and zero counts.
- `mintage-validation.png`: an invalid count keeps the editor open with an inline
  message, invalid-field semantics and focus on the first error.

The screenshots are generated by the STRK-391 workflows in the core Collections
suite. Browser tests cover create, edit, clear, clone, insert/reorder, reopen and
reload; existing Collections export/import and ZIP restore tests additionally
assert Mintage preservation. Unit tests cover strict numeric validation,
defensive normalization, identity/link/artwork preservation and managed sync
convergence. See the PR for exact verification totals and reviewer results.
