# StakTrakr v3.36.80: readable themes, safer Collections and image links

This release makes every theme readable, keeps Collections safe across tabs and adds image links to Items and Collections.

- Filter chips, vendor names, status text and charts meet AA contrast in every theme and follow a theme switch.
- Two open tabs keep each other's Collections and artwork. Backups include the newest artwork.
- Each Item image frame has an image options button: add an image link or use a matching pattern image.
- Custom Collection title images accept a live image link. Builder Slot thumbnails follow the collection's Image shape.
- Buttons respond right after the app loads, and clicks pass through toasts.
