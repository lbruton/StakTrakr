## Implementation Details

### Components Built (5 of 5)
1. **Enhanced Spot Cards** — 4 metal cards with Lightweight Charts (`lightweight-charts@4`) area series as translucent sparkline backgrounds. 7-day history data, metal-colored fills at 30% opacity. All axes/grid/crosshair hidden. Prices from `/v2/spot/latest.json`, sparkline from `/v2/spot/history/7d.json`.

2. **Retail Price Ranges** — CSS-only horizontal bars grouped by metal (gold, silver, platinum, palladium). Each bar shows low-median-high range with positioned median marker. Metal-colored gradient fills. Data from `/v2/retail/latest.json`.

3. **Premium Heat Map** — ApexCharts (`apexcharts@4`) heatmap. Rows = coins, columns = vendors. Cell color = premium % over spot. Color scale: vivid green (0-3%) > deep green (3-6%) > amber (6-10%) > orange (10-15%) > red (15-25%) > deep red (>25%). Data labels show premium %. Custom tooltip with price, premium $, vendor name, carried/OOS flags.

4. **Goldback Calculator** — CSS-only. G1 rate display, 5 denomination cards (G1-G50) with face value and gold melt value calculated from spot. Data from `/v2/goldback/latest.json` with graceful 404 handling.

5. **Best Price Ticker** — CSS-animated scrolling strip showing cheapest in-stock vendor per coin. Each item: metal dot, coin name, vendor, price, premium %. Duplicated items for seamless scroll animation. Static layout if < 4 items.

### Theme Support
All 3 themes implemented with exact CSS custom property values from production `css/styles.css`:
- **Dark**: saturated high-contrast colors (gold #fbbf24, silver #d1d5db, etc.)
- **Light**: darker tones for readability on white (gold #a04808, silver #5f6673, etc.)
- **Sepia**: warm muted palette (gold #80620a, silver #706b66, etc.)

Metal colors are theme-aware — sparklines, range bars, and ticker dots all update on theme change.

### Responsive Grid
- Mobile: single column, spot cards 2-col
- 768px+: market grid becomes 2-col (ranges + heatmap side by side)
- 960px+: spot cards expand to 4-col
- 1280px+: max-width container

### Component Toggles
Checkbox panel at top toggles each component with `hidden` attribute. Grid reflows with no dead space via CSS grid auto behavior.

### Libraries Used (CDN only)
- `lightweight-charts@4` (TradingView) for spot card sparklines
- `apexcharts@4` for premium heat map

### API Endpoints Used
- `GET /v2/spot/latest.json` — current spot prices
- `GET /v2/spot/history/7d.json` — 7-day spot history
- `GET /v2/retail/latest.json` — retail price summaries
- `GET /v2/retail/{slug}/latest.json` — per-coin vendor details
- `GET /v2/goldback/latest.json` — goldback denomination rates
