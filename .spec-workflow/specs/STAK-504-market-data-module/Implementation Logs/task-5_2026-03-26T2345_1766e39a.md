## What was implemented

Created `js/market-data.js` — the market data module orchestrator with best price ticker.

### Module state
- `_marketDataInitialized` guard prevents double init
- `V2_API` constant for the v2 API base URL
- `_METAL_TO_ISO` mapping (silver->xag, gold->xau, etc.) for CSS class assignment
- `_fmtPrice()` number formatting helper

### Helpers
- `_getSpotPrice(metalCode)` — reads from global `spotPrices`, falls back to DOM spot card elements
- `_getRetailCoins()` — reads from `window._v2RetailData.prices`, falls back to `loadDataSync('v2RetailPrices')`
- `_getCoinMeta()` — reads from `window._manifestCoinMeta`, falls back to `getRetailCoinMeta()` function or localStorage
- `_getVendorMeta()` — reads from `window._manifestVendorMeta`, falls back to localStorage

### Ticker (`renderBestPriceTicker`)
- Reads retail coins and coin metadata
- Skips goldback coins
- Builds items with slug, name, metal, bestPrice (lowest_price), vendorCount, premium over spot
- Sorts by premium ascending (best deals first)
- Hides container when no items
- Builds DOM using safe methods (createElement, textContent, appendChild)
- Duplicates items for seamless loop scroll when >= 4 items
- Adds `.static` class when < 4 items
- All text sanitized via `sanitizeHtml()`

### Init / Refresh
- `initMarketData()` — async, reads cached data from multiple sources, populates window globals, renders ticker
- `refreshMarketData()` — sync re-render from cached data
- Both have stubs for `renderVendorPrices()` (Task 6)

### Window exports
- `window.initMarketData`
- `window.refreshMarketData`
- `window.renderBestPriceTicker`
