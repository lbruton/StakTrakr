## What was implemented

Replaced the `renderVendorPrices()` stub in `js/market-data.js` with a full vendor price comparison table.

### New functions

- `_shortVendor(vid)` — maps vendor IDs to short display names (APMEX, JM, SD, Monument, Hero, BullionX, Summit, G'ville, Provident, Goldback)
- `openMarketDetailModal(slug)` — stub for Task 7 detail modal, logs via debugLog
- `_renderVendorTable(metalCode)` — async function that fetches per-coin vendor detail from V2 API and builds the comparison table
- `renderVendorPrices()` — builds the 5-metal tab bar (Gold, Silver, Platinum, Palladium, Goldback) and triggers initial table render

### renderVendorPrices behavior
- Gets container via `safeGetElement('vendorPricesContainer')`
- Empty state: "Retail data unavailable" when no coins
- Tab bar with 5 metal buttons, active tab persisted via `saveDataSync('vendorPricesActiveTab')`
- Default tab: silver (xag) — most populated metal
- Tab click: saves preference, updates active class, calls `_renderVendorTable()`

### _renderVendorTable behavior
- Filters coins by metal code using `_getCoinMeta()` and `_METAL_TO_ISO` mapping
- Shows loading state while fetching
- Parallel fetches per-coin detail from `V2_API + '/retail/' + slug + '/latest.json'` using `Promise.allSettled()`
- Collects all unique vendor IDs across fetched coins
- Builds `<table>` with headers: COIN | vendor names | MEDIAN | SPREAD
- Per-vendor cells:
  - In-stock prices shown with `$` prefix, monospace, clickable (opens vendor popup)
  - Premium badge below price: low (<5%), mid (5-15%), high (>15%) with color classes
  - Best in-stock price per row gets `.vp-best` class
  - Carried prices get `.vp-carried` class
  - OOS items show "OOS" with `.vp-oos` class
  - Missing data shows em-dash
- Coin name cell includes metal dot, sanitized name, and "Details" button (stub for Task 7)
- Vendor popup uses `window.retailProviders[slug][vendorId]` with fallback to `vendorMeta[vid].url`

### Init/Refresh integration
- `initMarketData()` and `refreshMarketData()` now call `renderVendorPrices()`
- Global exposure: `window.renderVendorPrices`, `window.openMarketDetailModal`
