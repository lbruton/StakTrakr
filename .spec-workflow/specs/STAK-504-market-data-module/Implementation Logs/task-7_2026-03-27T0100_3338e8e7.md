## What was implemented

Created `js/market-charts.js` (Lightweight Charts wrapper) and replaced the `openMarketDetailModal()` stub in `js/market-data.js` with a full modal implementation including chart, price summary, and vendor comparison table.

### New file: js/market-charts.js

- `getChartThemeColors()` — reads CSS custom properties from `document.documentElement` for theme-aware chart colors (bg, text, border, success, danger, and per-metal colors)
- `createCoinChart(containerId, metalCode)` — creates a TradingView Lightweight Charts AreaSeries with 7d spot history from `v2SpotHistory` localStorage cache. Guards with `typeof LightweightCharts` check. Returns chart instance or null.
- `destroyCoinChart(chart)` — safely removes a chart instance
- All three exported on `window`

### Updated functions in js/market-data.js

- `openMarketDetailModal(slug)` — async function that:
  1. Opens the `#marketDetailModal` overlay, wires close button/backdrop/Escape handlers
  2. Fetches per-coin detail from `V2_API + '/retail/' + slug + '/latest.json'`
  3. Fetches/caches 7d spot history from `V2_API + '/spot/history/7d.json'` (1h TTL via `v2SpotHistoryTs`)
  4. Builds modal content: header with coin name + metal badge + weight, price summary row (median/low/high/spread), chart container with `createCoinChart()`, and vendor comparison table sorted by price ascending with premium badges, stock status, and buy links
- `closeMarketDetailModal()` — destroys chart, clears content, hides overlay, removes Escape listener
- `_modalEscHandler(e)` — Escape key handler for modal
- `_activeModalChart` module variable for chart lifecycle

### Convention compliance

- `safeGetElement()` for all static page elements (overlay, content, close button)
- `document.getElementById()` only for dynamically created chart container inside modal
- `loadDataSync()`/`saveDataSync()` for spot history cache (keys already in ALLOWED_STORAGE_KEYS from Task 1)
- `sanitizeHtml()` on all coin/vendor names
- `debugLog()` for logging
- `watermark: { visible: false }` on chart
- `typeof` guards on LightweightCharts and createCoinChart
- Buy links use same popup pattern as Task 6
