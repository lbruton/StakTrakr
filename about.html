Goldback Support

Encrypted Cloud Sync

Sync your stack across devices without trusting anyone with your data. Everything is encrypted client-side before it leaves your browser.

Zero-Knowledge Encryption

AES-256-GCM with PBKDF2-SHA256 (100k iterations) via the Web Crypto API. Your cloud provider receives only ciphertext.

Visual Diff & Merge

When changes arrive, review item-level and settings-level diffs with click-to-pick field selection. Cherry-pick exactly what to keep.

Optional API Integrations

StakTrakr works fully out of the box with its bundled free API. Two optional integrations can enhance the experience — both are free and completely optional.

Integration What It Does Key
StakTrakr API Live spot prices and retail market data from major dealers. Powers spot cards, sparklines, ticker, and vendor comparison. Bundled
Numista Coin catalog search, automatic image population, composition/weight/series metadata sync, and tag import. Dramatically enriches your inventory. Optional
PCGS CoinFacts PCGS number lookup and cert verification for graded coins. One-click verification badges in the inventory table. Optional
Metals.dev Higher-frequency spot price updates (15-min intervals). Add as a secondary provider in Settings for faster refresh. Optional
MetalPriceAPI Alternative spot price provider with broad metal coverage. Configurable as primary or fallback in the provider priority chain. Optional
Metals-API Another spot price source option. Supports gold, silver, platinum, and palladium with historical lookups. Optional
Custom API Bring your own spot price endpoint. Point StakTrakr at any JSON API that returns metal prices in your preferred format. Optional

Numista keys are free at numista.com/api. PCGS keys are free at pcgs.com/coinfacts. Metals.dev keys are free at metals.dev. All configured in Settings > API.

Privacy Is Not a Feature — It's the Architecture

How StakTrakr Protects Your Data

  • No server-side component — the developer has no technical means to access your data
  • No account creation, no email collection, no user profiles
  • No cookies, no tracking SDKs, no advertising, no analytics fingerprinting
  • All data stored locally in your browser (localStorage + IndexedDB)
  • Cloud backup is zero-knowledge — encrypted before leaving your device
  • Full source code is open and auditable — MIT licensed
  • Works offline and runs from a local file — no server required
  • Cloudflare Web Analytics on the hosted site is aggregated page views only — no cookies, no fingerprinting, not present locally
